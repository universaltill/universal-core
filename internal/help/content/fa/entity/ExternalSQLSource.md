منبع SQL خارجی یک اتصال ثبت‌شده به یک پایگاه‌داده خارجی است — SQL
Server یک ERP قدیمی، یا هر پایگاه‌داده Postgres/SQL Server که می‌خواهید
از طریق جادوگر ورود از آن رکورد بکشید. برخلاف **اتصال ارائه‌دهنده
هوش مصنوعی**، این یک فهرست است، نه یک رکورد تنظیمات واحد: می‌توانید
چندین منبع ثبت کنید و هر بار که یک ورود اجرا می‌کنید یکی را انتخاب
کنید.

## چه زمانی استفاده شود

پیش از اجرای یک ورود مبتنی بر SQL — برای مثال، مهاجرت داده‌های مشتری و
اقلام از یک سیستم قدیمی به این پلتفرم — یک منبع SQL خارجی ثبت کنید.

## ثبت یک منبع

1. به **تنظیمات ← منابع SQL** بروید و افزودن منبع جدید را انتخاب کنید.
2. یک نام، درایور (SQL Server یا Postgres)، میزبان، پایگاه‌داده و در
   صورت نیاز پورت، نام کاربری و رمز عبور وارد کنید.
3. ذخیره کنید. رمز عبور پیش از ذخیره‌سازی رمزگذاری می‌شود و پس از آن
   هرگز به شما نشان داده نمی‌شود — خالی گذاشتن فیلد رمز عبور در
   ویرایشی بعدی، رمز عبور موجود را بدون تغییر نگه می‌دارد، نه پاک
   می‌کند.
4. پیش از تکیه بر آن برای یک ورود، از **آزمایش** برای تأیید این‌که
   اتصال واقعاً کار می‌کند استفاده کنید.

## قواعدی که باید بدانید

- نام، درایور، میزبان و پایگاه‌داده الزامی‌اند. نام کاربری، پورت، رمز
  عبور و گزینه‌های اضافی مخصوص درایور اختیاری‌اند — برخی منابع به‌طور
  مشروع به هیچ رمز عبوری نیاز ندارند (برای مثال، یک پایگاه‌داده محلی
  بدون رمز عبور).
- این صفحه تنظیمات مشخصاً به نقش `tenant_admin` نیاز ندارد — برخلاف
  اتصال ارائه‌دهنده هوش مصنوعی، هر کاربری با دسترسی به این حوزه
  تنظیمات می‌تواند منابع را مدیریت کند، پس مراقب باشید چه کسی این
  دسترسی را دارد.
- جزئیات اتصال به‌عنوان فیلدهای جداگانه، نه یک رشته اتصال واحد،
  ذخیره می‌شوند، تا صفحه تنظیمات بتواند آن‌ها را یکی‌یکی ویرایش کند و
  رمز عبور بدون وارد کردن دوباره همه‌چیز دیگر جایگزین شود.

## به چه چیزی متصل است

هر دوی **سیستم مرجع رکورد** و **هویت خارجی** به یک منبع SQL خارجی
ارجاع می‌دهند — اولی برای اعلام مالک رکوردهای واردشده، دومی برای
به‌خاطر سپردن این‌که یک ورود مشخص از کدام رکورد قدیمی آمده است.
