اتصال ارائه‌دهنده هوش مصنوعی، بک‌اند هوش مصنوعی پیکربندی‌شده خود
مستأجر شما برای ویژگی‌های پشتیبانی‌شده با تولید متن، مانند پیشنهاد
نگاشت ستون در جادوگر ورود است. هر مستأجری از قبل یک گزینه پیش‌فرض
مشترک و خودمیزبانی‌شده را رایگان دریافت می‌کند؛ این همان راهی است که
به‌جای آن به حساب Anthropic یا OpenAI خودتان (هزینه خودتان، کلید
خودتان، انتخاب صریح خودتان درباره نحوه پردازش داده آن ارائه‌دهنده)، یا
به سرور جداگانه خودمیزبانی‌شده خودتان به‌جای سرور مشترک، می‌پیوندید.

## چه زمانی استفاده شود

این را فقط زمانی پیکربندی کنید که مشخصاً می‌خواهید به‌جای پیش‌فرض
مشترک از حساب ارائه‌دهنده هوش مصنوعی خودتان استفاده کنید — اکثر
مستأجران هرگز نیازی به دست زدن به این ندارند.

## پیکربندی اتصال شما

1. به **تنظیمات ← ارائه‌دهنده هوش مصنوعی** بروید. این صفحه مشخصاً به
   نقش `tenant_admin` نیاز دارد — کاربری با نقشی متفاوت و غیرمدیریتی،
   حتی با وجود دسترسی واقعی دیگر در سیستم، در اینجا صفحه دسترسی رد شد را
   می‌گیرد.
2. ارائه‌دهنده خود را انتخاب کنید: گزینه مشترک خودمیزبانی‌شده، یا حساب
   Anthropic یا OpenAI خودتان.
3. برای سرور خودمیزبانی‌شده خودتان، آدرس آن را وارد کنید. برای
   Anthropic یا OpenAI، مدل و کلید API خود را وارد کنید.
4. ذخیره کنید. کلید API پیش از ذخیره‌سازی رمزگذاری می‌شود و پس از آن
   هرگز به شما نشان داده نمی‌شود.

## قواعدی که باید بدانید

- دقیقاً یک اتصال ارائه‌دهنده هوش مصنوعی به‌ازای هر مستأجر وجود دارد —
  این یک رکورد تنظیمات واحد است، نه فهرستی مانند منبع SQL خارجی.
  ذخیره دوباره، همان رکورد را به‌جای ایجاد یک رکورد جدید به‌روزرسانی
  می‌کند.
- این نوع رکورد فرم ورود داده تولیدشده خودش را ندارد و حتی توسط یک
  مدیر نیز نمی‌توان از طریق صفحات معمول رکورد آن را ایجاد یا ویرایش
  کرد — تنظیمات ← ارائه‌دهنده هوش مصنوعی تنها راه تغییر آن است،
  دقیقاً به این دلیل که کلید API باید رمزگذاری‌شده بماند و هرگز به‌صورت
  متن ساده به مرورگر بازنگردد.

## به چه چیزی متصل است

یک اتصال ارائه‌دهنده هوش مصنوعی کاملاً مستقل است — به‌جای این‌که
توسط رکوردهای دیگر ارجاع داده شود، توسط ویژگی‌های پشتیبانی‌شده با
هوش مصنوعی (مانند پیشنهادهای نگاشت ورود) مورد استفاده قرار می‌گیرد.
