مصدر SQL خارجي هو اتصال مسجَّل بقاعدة بيانات خارجية — SQL Server لنظام
ERP قديم، أو أي قاعدة بيانات Postgres/SQL Server تريدون سحب سجلات منها
عبر معالج الاستيراد. على عكس **اتصال مزود الذكاء الاصطناعي**، هذه قائمة،
لا سجل إعدادات واحد: يمكنكم تسجيل عدة مصادر واختيار واحد في كل مرة
تُشغِّلون فيها استيراداً.

## متى تستخدمه

سجِّلوا مصدر SQL خارجي قبل تشغيل استيراد قائم على SQL — على سبيل المثال،
ترحيل بيانات العملاء والأصناف من نظام قديم إلى هذه المنصة.

## تسجيل مصدر

1. اذهب إلى **الإعدادات ← مصادر SQL** واختر إضافة مصدر جديد.
2. أدخل اسماً ومحرِّكاً (SQL Server أو Postgres) ومضيفاً وقاعدة بيانات،
   وعند الحاجة منفذاً واسم مستخدم وكلمة مرور.
3. احفظ. تُشفَّر كلمة المرور قبل تخزينها ولا تُعرض لكم مرة أخرى أبداً
   بعد ذلك — ترك حقل كلمة المرور فارغاً في تعديل لاحق يُبقي كلمة المرور
   الحالية دون تغيير بدلاً من مسحها.
4. استخدموا **اختبار** للتأكد من أن الاتصال يعمل فعلاً قبل الاعتماد
   عليه في استيراد.

## قواعد يجب معرفتها

- الاسم والمحرِّك والمضيف وقاعدة البيانات مطلوبة. اسم المستخدم والمنفذ
  وكلمة المرور والخيارات الإضافية الخاصة بالمحرِّك اختيارية — بعض
  المصادر لا تحتاج مشروعاً إلى أي كلمة مرور (قاعدة بيانات محلية بلا كلمة
  مرور، مثلاً).
- لا تتطلب صفحة الإعدادات هذه دور `tenant_admin` تحديداً — على عكس اتصال
  مزود الذكاء الاصطناعي، يمكن لأي مستخدم لديه وصول إلى منطقة الإعدادات
  هذه إدارة المصادر، لذا انتبهوا لمن يملك هذا الوصول.
- تُخزَّن تفاصيل الاتصال كحقول فردية، لا كسلسلة اتصال واحدة، بحيث تستطيع
  شاشة الإعدادات تعديلها واحداً واحداً ويمكن استبدال كلمة المرور دون
  إعادة إدخال كل شيء آخر.

## بماذا يرتبط

كل من **نظام السجل الرسمي** و**الهوية الخارجية** يشيران إلى مصدر SQL
خارجي — الأول لإعلان مالك السجلات المستوردة، والثاني لتذكُّر السجل
القديم الذي جاء منه استيراد معين.
